# Study Planner

A simple web app to plan your studies. Add subjects, add tasks under each subject, and tick them when they are done.

## Features

- Add subjects (for example: Python, Maths)
- Add tasks under each subject
- Tick a task when it is done (the text gets a line through it)
- Delete a task
- Data is saved in the browser with `localStorage`, so it stays after you close the page
- Clean dark theme (a light theme is included in `style-light.css`)

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Type a subject name and click **Add Subject**.
4. Type a task under the subject and click **Add Task**.
5. Tick the box when the task is done.
